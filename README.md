# ugcadtestingos.com

Static landing page for UGC Ad Testing OS.

- `index.html`: landing page
- `styles.css`, `script.js`: styles, cookie consent and analytics events
- `privacy.html`, `terms.html`, `refund.html`, `support.html`: legal and support pages
- `assets/`: images

Do not change without review: the Stripe payment link (the Make delivery automation depends on it), the Google Analytics ID and the `data-consent-*` cookie logic.
